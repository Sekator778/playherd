## Коротко для Herd
- Формула цены ликвидации у Herd — формула Hyperliquid (Р-7); потолок плеча Herd (×250…×4000 в зависимости от рынка и ставки, EHW §2.5) выше всех площадок из базы: Hyperliquid 3–40x (на `xyz` до 50x), Binance до 125x (2019), MEXC 200x–1000x на отдельных продуктах, ESMA для розницы 30:1 … 2:1. Смягчает потеря не больше ставки и раунд 3–15 мин (`game_economy_proposal.md` §7 п. 2).
- При ликвидации Hyperliquid оставляет остаток трейдеру при закрытии через стакан и не возвращает поддерживающую маржу при backstop; Binance списывает «Liquidation Clearance Fee»; dYdX берёт штраф до 1,5 %; GMX v2 — неизвестно. Herd штрафа не берёт и платит остаток по крайней цене свечи (Р-93).
- Цена ликвидации у Hyperliquid считается по mark price (медиана трёх входов), не по цене последней сделки; Herd проверяет ликвидацию по `low`/`high` минутной свечи пути раунда.
- Лимиты тонких рынков: урок JELLY (Hyperliquid, март 2025) и YFI/SUSHI (dYdX v3, 2023) — Herd отвечает лимитом открытого номинала на (рынок, сторону, раунд) через `stress` и страховым механизмом казны.
- Замеры на стенде 2026-10-18 (аудит за 72 ч, 77 112 позиций, 0 расхождений): на предельном плече ступени ликвидируется у ботов 5–14 % позиций (BTC 3 мин — 5,1 %, 15 мин — 10,3 %), ниже 80 % предела — 0,2–0,5 %; людей на предельном плече в выборке 2 (см. раздел «Замеры»).

### Herd: правила одной строкой
| Правило | Источник | Прочитано |
|---|---|---|
| Номинал `N = S·L`, изолированная маржа = ставка `S`; цена ликвидации по формуле Hyperliquid: лонг `P0·(1 − 1/L)/(1 − l)`, шорт `P0·(1 + 1/L)/(1 + l)`; `l = κ / cap(рынок, длина раунда)`, `κ = 0,1` для цен, `0,5` для шансов; проверка по `low ≤ P_liq` (лонг) / `high ≥ P_liq` (шорт) на каждой свече пути, до расчёта по закрытию | EHW §2.1, §2.3 (не копируется); `LiquidationCalculator.java:67-86`; `PositionSimulator.java:55-85` | 2026-10-18 |
| При ликвидации: остаток маржи по крайней цене свечи срабатывания `max(0, S + s·Q·(P_ext − P0))`, без штрафа; гэп сквозь маржу даёт 0; прежнее «0 при ликвидации» (Р-7) осталось только для старых ставок | EHW §2.3; `LiquidationCalculator.java:129-139`; `GameEngine.java:198-213` | 2026-10-18 |
| Потолок плеча `maxL = min(cap, max(2, cap/d))`, `d` = 1 при `S ≤ 250`, 2 при `≤ 500`, 5 при `≤ 1 200`, 10 выше; `cap` по рынку и раунду (BTC 1200 в 3 мин / 500 в 15 мин; SP500 4000 / 2000; шансы 10) | EHW §2.4, §2.5; `EconomyRules.java:34-36,52-67` (`EconomyRules.maxLeverage`) | 2026-10-18 |
| Потолок выплаты одной ставки `min(20·S, 0,1 % казны)`; лимит открытого номинала на (рынок, сторона, раунд) `0,0025 · TREASURY / stress`; корзина крипторынков `1 % · TREASURY`; выключатель (казна ниже 90 % своего 30-суточного максимума: плечо новых ставок не выше `max(2, cap/4)`) | EHW §2.2, §4.1–§4.4; `EconomyLimits.java`; `GameService.java:2280-2345` | 2026-10-18 |

## Что Herd взял, чего не взял и почему
- **Формула цены ликвидации Hyperliquid.** Взята: Р-7 (2026-09-25); `LiquidationCalculator`, ставка `l` задаётся параметром по рынку (Р-69). Не реализованы: cross margin, ярус 1, backstop и частичная ликвидация, funding (HLM §2.1, §2.5).
- **Остаток при ликвидации.** Р-7 («теряется вся ставка») уточнён Р-93 (девять решений `game_economy_proposal.md` §7 п. 1): остаток возвращается по худшей цене свечи, штрафа нет. Поправка PFE: «Hyperliquid остаток не возвращает» верно только для backstop. Штраф Binance (clearance fee) и dYdX (до 1,5 %) не берём; PFE: Herd «честнее backstop Hyperliquid, Binance, dYdX».
- **Ступени плеча по размеру ставки.** Взяты у Hyperliquid как A3 (`EconomyRules.java:35-36`; `game_economy_proposal.md` §7 п. 2; EVA §2.2).
- **Потолки плеча.** Binance до 125x, MEXC 500x/1000x, ESMA — шкала для сравнения (PFE строка 200); Herd предлагает ×1000–×6000, «в 25–150 раз выше Hyperliquid», смягчено потерей ≤ ставки и раундом 3–15 мин; по умолчанию ползунок до ×100 (`game_economy_proposal.md` §7 п. 2). Числа `cap` в EHW §2.5 отличаются от этого диапазона (×250…×4000 при ставке до 250 PLAY) — см. «Расхождения».
- **ADL и делеверидж (Hyperliquid, Binance, dYdX).** Не берём: нарушают «выигрыш выплачивается» (`game_economy_proposal.md` §7; TS вывод 9). Частичную ликвидацию не берём.
- **Лимиты казны из GMX и Hyperliquid.** Потолок открытого интереса через резервный коэффициент и потолок PnL пула — идея лимитов казны (TS вывод 9); потолок хранилища относительно его размера и остановка рынка голосованием (= наш выключатель); урок JELLY — лимит смотрит на концентрацию на тонком рынке. Тонкие рынки (шансы Polymarket) — строже общих 0,25 %: Р-101 п. 2 (EVA §3).
- **Страховой фонд.** Образец Binance (99,9 % + стресс, пересмотр): у Herd — выметка кошелька Herd/ботов в казну и страховой запас (TS строка 273), пересчёт раз в неделю; образец dYdX — пополнение комиссиями ликвидаций. Урок YFI/SUSHI: «только крупные рынки; цена раунда — индекс нескольких источников» (TS строка 274).
- **Цена.** Herd не агрегирует биржи сам: читает `markPx` Hyperliquid (Р-11, Р-70) и свечи `candleSnapshot` (Р-23); крипта — спот Coinbase (запасной Kraken), HYPE — спот Hyperliquid (Р-76).
- **Плечо у PancakeSwap и Twitch отсутствует**; у Herd есть (`ux_first_glance_review_2026-10-16.md`, вывод).

## Расхождения и открытые вопросы
- **Остаток при ликвидации в Herd.** Р-7 в `decisions.md` и `docs/about/economics.md:26`: «0 — теряет всю ставку»; EHW §2.3 и код: для новых ставок остаток по крайней цене свечи (Р-93). Верно последнее; Р-7 в `decisions.md` не обновлён.
- **Потолок плеча Herd.** `game_economy_proposal.md` §7 п. 2 (по `venues/cex-futures.md`): ×1000–×6000; EHW §2.5: `cap` 250…4000 (BTC 1200 в 3 мин); ступени по размеру ставки снижают плечо при больших ставках. Оба источника сохранены; код и таблица `markets` — по EHW.
- **Максимальное плечо BTC на Hyperliquid.** HLM/HMA: 40x, ярус 150 млн; GEV §2 (2026-10-15): значение не указано (UNVERIFIED). Верен HLM/HMA (живой ответ + `margin-tiers.md`).
- **Ставка maintenance BTC.** PFE строки 90, 230: 2,5 % при 40x (UNVERIFIED); HLM §1.4: 1,25 % для tier0. 2,5 % — ставка яруса 1 (20x).
- **JELLY.** PFE строка 72: «2024» (onekey.so [С]); TS, EVA: 26.03.2025. Размер: TS — шорт ≈ $4 млн, убыток $12–13,5 млн, HLP ≈ +$703 тыс.; EVA — позиция ≈ $6 млн, +400 % цены, OI > 40 %; WNH — убыток ≈ $12 млн, закрытие по $0,0095. Не снято.
- **Лимит OI Hyperliquid.** После JELLY лимиты введены (TS, EVA), но спецификации 2026-10-17: «Position limit: N/A».
- **Binance: 125x** — данные 2019 года, актуальность на 2026 не установлена; перепроверить.
- **Не собрано (нужен внешний поиск):** ярусы плеча и maintenance margin Binance/Bybit/OKX/dYdX/GMX; остаток при ликвидации у GMX v2; лимиты OI dYdX и Kalshi/Pancake; страховые фонды Bybit/OKX; значения потолков OI основных перпов Hyperliquid; страница `auto-deleveraging` Hyperliquid дословно не сохранена.
- **Доля ликвидаций ~ 35 % (расчёт, EHW §2.5) и замер аудита** (5–14 % у ботов на предельном плече) — разные величины (расчёт на потолке с запасом 0,8 против факта по ботам); сопоставление в источниках не сделано, оба сохранены.
